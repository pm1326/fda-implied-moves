## 2. Out-of-sample backtest

Each model version is fitted on the 225 decisions before 2023, then forecasts the size of the move for the 263 decisions from 2023 onwards. The outcome (approved or rejected) is taken as known, so this tests how well the model sizes the move, not whether it predicts the FDA.

Average error is how far the forecast was from the actual move, in percentage points (lower is better). Rank correlation is whether the model puts decisions in the right order from small to large (higher is better).
